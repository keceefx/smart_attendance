# Smart Attendance System (Student Portal)

## 📌 Project Overview
The Smart Attendance System is a backend-integrated web application designed to streamline student verification, record-keeping, and attendance tracking. Built as part of Software Engineering coursework, this system eliminates manual paper-based logging by providing a reliable digital portal for capturing and managing student attendance data.

---

## 🚀 Key Features
* **Student Record Management:** Centralized database handling for student profiles and identification numbers.
* **Automated Attendance Tracking:** Streamlines logging and tracking of student presence for classes and academic activities.
* **Database Connectivity:** Built to securely connect and sync attendance data with a backend database.
* **Responsive UI:** Clean frontend interface designed for easy navigation on both desktop and mobile screens.

---

## 🛠️ Technology Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend / Logic:** PHP / Java / Node.js 
* **Database:** MySQL / XAMPP Local Environment
* **Environment:** Visual Studio Code
